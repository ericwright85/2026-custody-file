# Wright Family — Case Dashboard

> **Purpose:** the front door to the case. This page should let counsel understand the dispute, chronology, current work, and where to click next in a few minutes. Detailed analysis and source review live behind the links.

## Case in 60 seconds

**Case:** Sana seeks modification of the existing parenting arrangement. Eric opposes modification absent a demonstrated new child-centered reason and separately raises decree-compliance / enforcement issues. The repository uses **April 15, 2021** as the operative material-change baseline.

**Eric's position:** The shared parenting arrangement itself has not been shown to be failing. Eric's preferred outcome is for Rayan and Aleena to retain meaningful relationships with both parents, with greater practical flexibility and less adult conflict reaching them; absent a legally sufficient material change, the existing order should remain.

**Sana's position:** As reconstructed from the present record, Sana seeks greater possession and/or authority and relies on concerns involving Eric's parenting, safety, school, decision-making, parental conflict, and the children's welfare. Her current discovery responses and precise requested relief are still needed before this repository can state her present theory without inference from historical communications.

**Current commentary:** The clearest genuinely newer factual condition is Rayan's documented 2025–26 behavioral deterioration. The central unresolved questions are **what materially changed after 4/15/21, what caused any demonstrated harm, and why the modification Sana requests would remedy it.**

### Repository standard

This repository is intended to reconstruct the record, not manufacture a winning narrative. **Allegation is not proof; a child's report is not automatically proof of the underlying adult act; correlation is not causation; historical continuity is not material change; and evidence materially favoring Sana belongs in the model just as much as evidence favoring Eric.**
