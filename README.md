# Wright Family — Case File

> **Purpose:** a thin, clickable control page for counsel. Detailed factual analysis lives behind the links.

## Case summary
Sana seeks modification of the current parenting arrangement; Eric opposes modification absent a demonstrated new child-centered reason and separately raises decree-compliance/enforcement issues. The operative material-change date used by this repository is **April 15, 2021**.

## Eric's position
The shared parenting arrangement itself has not been shown to be failing. Eric's stated goal is meaningful, flexible relationships with both parents and less adult conflict reaching the children; if additional authority is required, it should protect those relationships rather than reduce either one as a reward or punishment.

## Sana's position
As reconstructed from the present record, Sana seeks greater custody/possession or authority and relies on concerns involving parenting, safety, school, decision-making, conflict, and the children's welfare. **Her current discovery responses and precise requested relief are needed to state her present position accurately rather than infer it from historical communications.**

## Commentary
The strongest current factual issue is Rayan's documented 2025–26 behavioral deterioration. The principal unresolved questions are what materially changed after 4/15/21, what caused any demonstrated harm, and whether the requested modification would remedy it.
