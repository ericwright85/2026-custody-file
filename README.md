# 2026 Custody File

Persistent case knowledge base and evidence index for the 2026 custody litigation.

## Core structure

- `index/themes.md` — main factual themes we are testing against the record
- `index/events.csv` — event-level evidence index (the backbone)
- `index/allegations.md` — allegation-by-allegation matrix, including pre/post 4/15/2021 history
- `index/evidence-map.md` — links TalkingParents events to outside evidence/witnesses
- `index/source-index.md` — source inventory and provenance
- `notes/case-theory.md` — evolving narrative / trial visualization notes

## Working rule

The repository is an evidence model, not an advocacy-only file. Facts that help Eric, hurt Eric, or are ambiguous all belong here. Patterns should emerge from indexed events rather than being assumed first.

## Material-change anchor

Primary chronology begins **4/15/2021**. Earlier evidence is retained when useful to show that an allegation, conflict pattern, or circumstance already existed before that date.
