# Sana Deposition Control Matrix

> **Use:** one-page-at-a-time deposition prep for counsel. This is not a script. It is a control surface: what proposition matters, what Sana has already said, what proof is linked, what needs to be pinned down under oath, and what each possible answer does to the case.

The organizing discipline for every module is:

`CLAIM → DATE → BASIS → CHILD IMPACT → CAUSATION → REMEDY → CONTRADICTION / CORROBORATION`

Counsel should feel free to reorder, delete, or collapse modules based on legal strategy and time.

# Deposition answer handling

Do not classify an answer merely as `good` or `bad` for Eric. Capture it as one of:

- **Admission** — supports a material proposition;
- **Denial** — creates a clean dispute to prove with another source;
- **New fact** — something not previously in the case model;
- **New source** — witness/document/provider/data we need to obtain;
- **Causal opinion** — distinguish personal belief from professional/firsthand basis;
- **Remedy explanation** — the claimed logical connection between fact and requested order;
- **Concession** — narrows the issue;
- **Memory failure / cannot identify basis** — useful only where fair and material;
- **Adverse answer** — strengthens Sana's theory and must be incorporated, not hidden.

Immediately after deposition, every material answer should flow into `sana-admission-ledger.md` with transcript page/line and the relevant Source IDs.

# Counsel calibration questions before deposition

Bruman should ideally mark this matrix with three quick decisions:

- **Must ask** — necessary to preserve/clarify trial theory;
- **Ask only if opened** — useful but risks distraction, privilege, or sympathy;
- **Do not ask** — strategically unnecessary or better saved for trial.

The historical Whiteaker / conflict-state material especially belongs in the second category until counsel decides relevance, privilege, remoteness, and whether opening that door helps more than it hurts.
