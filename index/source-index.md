## Linking convention

Going forward, promoted evidence should be referenced by stable Source ID wherever possible:

`Assertion → Source ID → direct source link → commentary / limitations → legal significance`

The source index is provenance-oriented. The [Evidence Link Registry](evidence-links.md) is attorney/navigation-oriented.
