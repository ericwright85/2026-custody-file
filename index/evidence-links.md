# Evidence Link Registry

This is the **click-through proof shelf** for the case file.

Use it when a review page or assertion makes you want to see the underlying item immediately. Gmail links require access to Eric's Gmail account; Google Drive links require access to the connected Drive. The repository should increasingly reference these Source IDs rather than forcing anyone to hunt through folders or print everything to PDF.

## How to read an evidence entry

Each entry follows the same pattern:

> **Assertion** — what proposition the item may support.  
> **Proof** — the underlying source.  
> **Commentary** — what it proves, what it does not prove, and any important adverse/context reading.

## Source-linking rule going forward

Whenever practical, every promoted proposition should have:

`Assertion → Source ID → direct evidence link → review/commentary → legal significance`

A PDF copy is still useful when authentication, production, or trial exhibit handling requires it, but **a source does not need to be printed to PDF merely to be usable inside this case brain**.
